# Green Chat — MAX · Telegram · WhatsApp через GREEN-API

Веб-клиент для отправки и получения текстовых сообщений через [GREEN-API](https://green-api.com/max).
Основной сценарий — **MAX** (интерфейс по мотивам [web.max.ru](https://web.max.ru/)); дополнительно
поддержаны **Telegram** и **WhatsApp**: у каждого мессенджера своё оформление, похожее на его веб-версию,
а переключаться между ними можно в одном окне.

**Демо:** https://karl-kane.github.io/GreenAPI/

## Возможности

- Вход по `apiUrl`, `idInstance`, `apiTokenInstance` с проверкой авторизации инстанса (`getStateInstance`)
- Новый чат по номеру телефона: номер проверяется в мессенджере (`checkAccount` для MAX/Telegram, `checkWhatsapp` для WhatsApp)
- Отправка текста — [`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/)
- Получение сообщений — [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/): long-polling `ReceiveNotification` → обработка → `DeleteNotification`
- Статусы доставки (отправлено / доставлено / прочитано), повторная отправка при ошибке
- Сообщения, отправленные с телефона, тоже появляются в чате
- Несколько мессенджеров одновременно: неактивные продолжают принимать сообщения, счётчики непрочитанных видны на боковой панели
- История чатов сохраняется в `localStorage`
- Адаптивная вёрстка для телефона

## Быстрый старт

Нужен Node.js 20+.

```bash
git clone https://github.com/Karl-Kane/GreenAPI.git
cd GreenAPI
npm install
npm run dev
```


### Подготовка инстанса GREEN-API

1. Зарегистрируйтесь в [личном кабинете](https://console.green-api.com) и создайте инстанс для MAX (подойдёт бесплатный тариф Developer).
2. Авторизуйте в инстансе свой аккаунт MAX.
3. В настройках инстанса оставьте **пустым `webhookUrl`** и включите уведомления о входящих и исходящих сообщениях — иначе HTTP API не получит уведомления.
4. Скопируйте `apiUrl`, `idInstance` и `apiTokenInstance` и введите их на экране входа.

### Проверка сценария из задания

1. Войдите с данными инстанса.
2. Нажмите ✎ «Новый чат» и введите номер получателя, зарегистрированного в MAX.
3. Напишите сообщение — оно придёт получателю в MAX.
4. Ответ получателя появится в чате через пару секунд.

## Деплой

При каждом пуше в `master` GitHub Actions (`.github/workflows/deploy.yml`) прогоняет тесты, собирает проект и публикует `dist/` на GitHub Pages.

## Структура

```
src/
  api/greenApi.ts          HTTP-клиент GREEN-API и понятные тексты ошибок
  messengers.ts            Отличия мессенджеров (как получить chatId по номеру)
  lib/notifications.ts     Разбор уведомлений в события чата
  state/accountReducer.ts  Состояние чатов: дедупликация, статусы, непрочитанные
  hooks/useAccount.ts      Long-polling очереди уведомлений, отправка, сохранение
  components/              UI: панель мессенджеров, вход, список чатов, переписка
  index.css, themes.css    Общая вёрстка и три темы (MAX / Telegram / WhatsApp)
```

Компоненты используют только CSS-переменные, а тема выбирается атрибутом `data-messenger`. Поэтому новый мессенджер добавляется конфигом и набором переменных, без изменения компонентов.

## Ограничения

- Поддерживаются только текстовые сообщения, как требует задание; медиа отображаются заглушкой.
- Учётные данные хранятся в `localStorage` браузера и отправляются только на указанный `apiUrl`.
- Одну очередь уведомлений инстанса должен читать один клиент. Если открыть приложение с тем же инстансом в двух вкладках, они будут забирать уведомления друг у друга.

## Стек
